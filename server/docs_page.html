🔔 Webhooks — Push Notifications

Stop polling! Configure webhooks and get POST notifications when new trends match your criteria. Free tier: 1 webhook, 6-hour delay. Paid: up to 10 webhooks, hourly delivery.

POST /v1/webhooks Free 1 Paid 10
Create a webhook subscription — validates URL is reachable, returns webhook ID
ParameterTypeDescription
urlstringRequired: Your callback URL (must be reachable)
categoriesarrayOptional: filter by categories (e.g. ["科技","娱乐"])
min_heatintOptional: minimum heat score filter
source_filterarrayOptional: filter by sources (e.g. ["weibo","baidu"])
event_typestringOptional: new_trend (default), viral_alert, or daily_digest

Example

curl -X POST http://161.153.56.113:8900/v1/webhooks \
  -H "X-API-KEY: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://your-server.com/webhook-callback","categories":["科技"],"min_heat":100000,"event_type":"new_trend"}'
GET /v1/webhooks Free Paid
List webhooks — returns all webhooks with status, last delivery, and delivery count

Example

curl -H "X-API-KEY: YOUR_KEY" \
  http://161.153.56.113:8900/v1/webhooks
DELETE /v1/webhooks/{id} Free Paid
Delete a webhook — permanently removes the webhook subscription

Example

curl -X DELETE http://161.153.56.113:8900/v1/webhooks/YOUR_WEBHOOK_ID \
  -H "X-API-KEY: YOUR_KEY"
POST /v1/webhooks/{id}/test Free Paid
Send test event — delivers a sample trend payload to verify your webhook endpoint works

Example

curl -X POST http://161.153.56.113:8900/v1/webhooks/YOUR_WEBHOOK_ID/test \
  -H "X-API-KEY: YOUR_KEY"
